# 🚀 Zomato Bangalore Market Intelligence & Full-Stack Data Science Pipeline

An executive-grade, end-to-end data science and analytics portfolio project exploring the Bangalore restaurant ecosystem. This repository demonstrates a complete production-grade workflow—from raw relational database engineering and advanced SQL analytics to machine learning modeling and interactive business intelligence dashboards.

---

## 📊 Executive Summary
The goal of this project is to deliver actionable market intelligence for restaurant expansion and culinary positioning in Bangalore. Utilizing a comprehensive multi-source dataset, this capstone answers critical business questions regarding pricing elasticity, cuisine profitability, customer ratings, and geographic demand concentrations.

🛠️ Key Technical Components
1. Relational Database Analytics (01_SQL_Database_Analytics)
Engine: PostgreSQL / pgAdmin 4

Highlights: Multi-table schema design, complex JOINs, Common Table Expressions (CTEs), and Window Functions to isolate top-performing localities and cuisine segments by rating and aggregate turnover.

2. Machine Learning Pipeline (02_Python_Machine_Learning)
Framework: Scikit-Learn, Pandas, NumPy

Artifacts: app.py, train_pipeline.py, model_pipeline.pkl

Highlights: Automated data cleaning loaders, feature engineering, robust model training (Random Forest Regressor), and a 4-panel diagnostic evaluation dashboard (capstone_model_evaluation.png).

3. Business Intelligence & Dashboarding (03_BI_Dashboards)
Tools: Power BI, DAX

Artifacts: DAX_Measures.txt, Zomato_Banglore_PowerBI_Dashboard.PNG, Zomato_Executive_Intelligence.pdf

Highlights: Dynamic executive metrics measuring customer sentiment, cost-to-rating ratios, and regional density mapping. (Note: Full .pbix source file archived locally due to GitHub repository size thresholds).

4. Executive Documentation (04_Executive_Documentation)
Files: Task_6_Final_Data_Science_Capstone_Project.docx

Highlights: Comprehensive business documentation structured for stakeholders, detailing data governance, technical architecture, quantitative findings, and strategic recommendations.
